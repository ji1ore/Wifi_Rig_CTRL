# Wifi_RIG_CTRL v3.06 リリースノート

**バージョン**: 3.06 (versionCode 85)  
**リリース日**: 2026-09-21

## 変更内容

### FT8画面 — ALC/パワー数値表示の追加

FT8画面のPO（パワー）・ALC（自動レベル制御）メーターに数値（%）を追加表示するようになりました。

- TX中にリアルタイムで数値が更新されます
- ALC値は引き続き赤色で表示
- TX終了時に自動的に0%にリセット
