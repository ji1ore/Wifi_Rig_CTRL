# Wifi_RIG_CTRL v3.06 Release Notes

**Version**: 3.06 (versionCode 85)  
**Release Date**: 2026-09-21

## Changes

### FT8 Screen — Numeric ALC / Power Display

The FT8 screen now shows numeric percentage values alongside the PO (power output) and ALC meters.

- Values update in real time during TX
- ALC value continues to be shown in red
- Both values reset to 0% automatically when TX ends
