# Wifi_RIG_CTRL v3.34 リリースノート

**バージョン**: 3.34（Android versionCode 161 / iOS build 78）  
**リリース日**: 2026-11-06

---

## 変更点

本バージョンは、**CW（モールス）受信デコードのノイズリダクション（NR）** を追加したアップデートです。

### CW デコード用 NR を追加（混信・雑音の多いバンド向け）

- CW デコード中に、**受信トーン（CW ピッチ）を中心とした狭帯域フィルタ**をアプリ内でかける NR を追加しました。RX 周波数をタップ（iOS は「NR」チップ）で ON/OFF できます。
- 近接する混信局やバンドノイズを抑え、**聞きやすさと復号率の両方**を改善します。中心はデコード中のピッチに合わせて固定され、再生音には軽い AGC（信号強調）がかかります。
- 従来 NR に使っていた afftdn（Pi 側 FFT ノイズ除去）は CW デコード中は使いません。そのため **CPU 負荷による音切れが発生しません**。
- NR の有無はお好みで切り替えられます（既定は OFF）。

### CW / RTTY 画面の GA・GE ボタンの左右配置を入れ替え

- あいさつマクロの GA と GE の並びを入れ替えました（誤操作防止）。

---

## Pi の更新について

**本バージョンは Pi API を 3.34 に更新します。** アプリの「Update Pi」ボタンから、アプリに同梱された新しい api.py を Pi に適用してください（Pi を自動で再起動します）。更新するとメイン画面の「Update」バッジが消えます。
